測試腳本

每一條都對應第 44 章「行銷與註冊官網」的一條規格。右下角測試面板可以改子網域保留秒數與付款結果。

1.2 功能介紹頁

  1. 打開「功能」→ 每個功能都標了哪些方案才有。
  2. 測試面板把「自訂主題」從成長改到專業 → 功能頁與定價頁的比較表同時改變——因為兩邊讀的是同一份方案定義。
  3. 任一功能按「看示範」→ 跳到示範站對應的畫面。

1.3 行業落地頁

  1. 「適用行業」→ 點任一行業 → 看到該行業的痛點、範本預設內容、推薦版型與配色。
  2. 在行業頁按「用這個行業開始」→ 結帳第 2 步的課程主題已經預先選好，而且可以改。
  3. 回「適用行業」按「自建主題看看」→ 說明可自訂名稱、套通用預設版型，並提示要設定的東西比較多。

1.4 示範站

  1. 「看示範」→ 任一行業 → 前台 → 免登入就能看，頂端有「這是示範站」提示。
  2. 走完預約三步 → 完成頁明確寫著沒有真的成立預約、沒有寄信、沒有收款。
  3. 切到後台示範 → 改任何欄位按儲存 → 被擋下，提示「示範站不可修改，註冊試用即可自己動手」。
  4. 在示範站切換配色 → 前台顏色即時改變。
  5. 看頁面下方說明 → 資料每日重置、不計入用量與經營數字。

1.5 結帳

  1. 定價頁切「年繳」→ 價格改變並顯示省多少。
  2. 結帳第 2 步子網域填 smalltree → 已被使用，擋下。填 admin → 保留字，擋下。填沒用過的 → 可用，並保留 30 分鐘開始倒數。
  3. 測試面板把保留秒數改成 20 秒，等它跑完 → 子網域釋出，回頭時提示要重新確認。
  4. 第 3 步發票類型選「公司」→ 統編與公司名變成必填。
  5. 優惠碼填 SPRING20 → 折 20%，金額即時試算。填 OLD10 → 已過期。填 FULL5 → 已用完。填亂碼 → 查無此優惠碼（四種訊息各不相同）。
  6. 不勾條款 → 付款按鈕停用。只勾條款不勾行銷訊息 → 可以送出，兩者是獨立的。
  7. 測試面板把付款結果設成「失敗」再付款 → 停在待付款、顯示原因、資料完全沒有被清掉，可直接重試。
  8. 改回「成功」再付 → 產生訂閱訂單與發票、狀態直接進「使用中」（跳過試用）、直接進導引設定。
  9. 看完成頁的同意紀錄 → 記下了條款版本號、時間與來源。

1.6／1.7 聯絡我們與大客戶

  1. 只填姓名和 Email 送出 → 成功——其他欄位都不是必填。
  2. 姓名留白 → 擋下。沒勾機器人驗證 → 擋下。
  3. 用同一個 Email 再送一次 → 合併成同一筆，不會建兩張工單。
  4. 看右側清單 → 來源是「官網諮詢」，狀態「待處理」，而且沒有建立租戶。
  5. 「大客戶報價」送出 → 同樣建工單但標記為報價需求並優先排序；分店數超過最高方案時會特別提示。

1.8 條款與必勾

  1. 頁尾點「服務條款」→ 獨立頁面，有版本號與生效日。
  2. 點「查看歷史版本」→ 列出舊版本，可切換閱讀。
  3. 結帳第 4 步 → 條款必勾預設不勾；行銷訊息是另一個獨立勾選框，也預設不勾。
  4. 兩份文件在結帳流程中點開 → 不會離開結帳流程（另開視窗）。
