測試腳本

每一條都對應規格的一條規則。右下角測試面板可切換身分（營運者／超管）與時間。

A 平台帳號、2FA 與成員

  1. 用 nobody@x.com 登入 → 與密碼打錯同一句訊息，不透露帳號是否存在。連錯 5 次 → 鎖定 15 分鐘。
  2. 密碼對了以後 → 一定會被要求輸入 2FA 驗證碼，跳不過去。
  3. 2FA 頁點「改用備援碼」，用一次某組碼 → 可登入；同一組再用第二次會被拒。
  4. 2FA 頁點「驗證器遺失了？」→ 不能自助重設，要另一位平台超管協助解除並留紀錄。
  5. 我的帳號 → 按「關閉 2FA」→ 被擋下：平台帳號強制啟用，本人與超管都不能關。
  6. 我的帳號 → 重新產生備援碼 → 舊的全部失效，新的只顯示一次。
  7. 把身分切成平台營運者 → 「邀請平台成員」被擋（限超管）；左側「方案管理」「範本與主題預設」變灰。

B 租戶總覽與詳情頁

  1. 搜尋框輸入 owner@smalltree.example → 用擁有者 Email 也搜得到那一家。
  2. 按「匯出目前結果」→ 出現對話框而不是直接下載：可選範圍（目前篩選／已勾選的列／重新指定狀態）與要匯出的欄位。
  3. 清單上勾兩三家，再按匯出 → 「只匯出已勾選的列」可選且顯示筆數；沒勾任何列時該選項是停用的。
  4. 勾了幾家之後改變篩選條件 → 勾選被清空（不會偷偷匯出被篩掉的租戶）。
  5. 欄位全部取消勾選 → 匯出按鈕停用並提示「至少要留一個欄位」。
  6. 關掉對話框再打開 → 上次的欄位選擇被記住。
  7. 對話框裡找「訂單」「學員」「課程營收」→ 根本不在欄位清單裡；匯出後平台紀錄那筆會記下筆數、欄位與當時的篩選條件。
  8. 點任一租戶進詳情頁 → 七個分頁都在；找不到訂單、學員或課程營收。
  9. 身分切成營運者，開「功能開關」分頁 → 看得到但改不了（覆寫限超管）。

C 訂閱、人工調整與退款

  1. 訂閱與催繳 → 對催繳中的租戶按「延長寬限」→ 必須填原因才能送出；狀態維持催繳中不轉停用。
  2. 按「手動標記已收款」→ 狀態轉回使用中。
  3. 詳情頁 → 延長試用 → 需填原因；同一家累計超過 2 次會被擋。
  4. 詳情頁 → 退款，金額填 5000（超過門檻）且身分是營運者 → 被擋，需平台超管核可。切成超管再試 → 通過。
  5. 退款成功後看訂閱狀態 → 沒有自動改變，是否停用要另外決定。
  6. 訂閱與催繳 → 爭議中的租戶 → 自動續扣已暫停，但沒有被停用。

D 方案管理

  1. 方案管理 → 預設只列上架中；狀態切「停售」看得到已停售的方案，整列以不同顏色顯示並標「停售」。
  2. 操作欄三個圖示 ✏️ 🚫 🗑️ → 滑過有 tooltip；點 🗑️ 會說明方案不能刪除只能停售。
  3. 搜尋框輸入「成長」→ 清單即時過濾。
  4. 編輯方案把價格調高 → 既有租戶的月費不變（讀成立時的價格快照），只有新訂閱吃新價。
  5. 把某方案的「老師數上限」調到比現有租戶用量還低 → 擋下，並列出已超過的租戶清單。
  6. 停售一個方案 → 既有訂閱照舊；開通與改方案的可選清單裡不再出現。

E 經營數字

  1. 切本月／上月／本季／今年 → 數字跟著變，且每個都顯示與前一期的增減。
  2. 看趨勢圖 → 12 根長條、每根標數值、本月為綠色。
  3. 整頁搜尋「課程營收」→ 找不到，只有訂閱收入。匯出檔案同樣不含。

F 退租與停用

  1. 停用租戶頁 → 欠費停用與主動退租都在同一張清單，資料標示「完整保留・不設期限」。
  2. 任一筆按「一鍵復用」→ 直接回到使用中，資料完好，不需重新開通。
  3. 整份後台搜尋刪除租戶的入口 → 找不到——平台後台不提供刪除，刪除依「法遵與資料權利」另循流程。
  4. 詳情頁 → 換子網域 → 提示舊子網域保留轉址 30 天才釋出。
  5. 詳情頁 → 轉移擁有者，選一個不在成員名單的人 → 被擋，要先邀請加入；並會明確詢問帳務聯絡人是否一併更換。

G' 工單

  1. 工單清單 → 每張都標來源：租戶後台提交／Email 轉入／平台代開（附代開者）／系統自動。
  2. 搜尋框輸入 1042 → 用編號就找得到。
  3. 狀態選「待處理」、來源選「系統自動」→ 兩個條件同時生效。
  4. 快速檢視選「逾時未回覆」→ 只留超過回覆時限的工單。

G 用量

  1. 接近上限清單 → 預設門檻 80%，列出達門檻的租戶與項目。
  2. 門檻改成 90% → 清單變短；左側徽章數字跟著變。
  3. 任一列按「談升級」→ 直接帶到該租戶的改方案。

H 代操（最重要）

  1. 詳情頁按「進入代操」→ 即使今天已經登入過，還是要再輸入一次 2FA。
  2. 進入後看學員資料 → 聯絡資料被遮蔽；姓名與訂單編號看得到，足以定位問題。
  3. 按「解除遮蔽」→ 要填原因；單次有效，看完自動恢復遮蔽，而且在平台紀錄留單獨一筆。
  4. 按「匯出學員名單」「更改金流收款帳號」「刪除資料」→ 三個都被擋，即使切成超管也一樣。
  5. 代操中去點另一家租戶的「進入代操」→ 被擋：同一時間只能代操一家。
  6. 測試面板把代操逾時改成 20 秒，然後放著不動 → 自動退出，平台紀錄的退出原因寫「逾時」。
  7. 從工單按「從工單進代操」→ 代操橫幅顯示工單編號，紀錄裡也帶著它。
  8. 退出後回平台紀錄 → 代操那筆是「有租戶歸屬」，切到租戶詳情頁的稽核分頁也看得到同一筆。

I 公告、維運與通知

  1. 公告選「全體租戶」→ 送出前顯示預計送達的租戶數。改成「依方案」→ 數字跟著變。
  2. 等級選「緊急」發布 → 標記為不可關閉，強制顯示直到已讀。
  3. 已發布清單 → 看得到已讀率；結束日到了會自動下架。
  4. 用標題、等級、日期區間篩選 → 三個條件都能單獨或合併使用；「清除」一鍵還原。
  5. 點 ✏️ 只改標題或等級 → 已讀率保留。改內文再存 → 已讀歸零並重新推播。
  6. 點 🗑️ → 二次確認；刪除後租戶端立即消失，與「提前下架」不同（下架保留紀錄與已讀率）。
  7. 維運 → 功能開關覆寫 → 必填原因與到期日；到期自動回到方案預設（可用測試面板 +100 天驗證）。
  8. 維運 → 平台端通知偏好 → 其他事件都能關，只有「隔離違規告警」關不掉。
  9. 身分切營運者 → 按「發布事故」→ 被擋（限超管）。
